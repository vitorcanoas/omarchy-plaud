# Demo image

[highlights.png](highlights.png) shows the Plaud Linux GTK3 highlights panel at
680 × 640 pixels. It was captured from the application with a fake recorder,
one synthetic note and two generated slide images. No real recording, account,
authentication data or personal screenshot appears in it. The image illustrates
the note editor, compact screenshot previews and nearby remove controls; it is
not evidence of a live Plaud service operation.
